# knife4go

Knife4j UI for Swagger 2.0 documents generated by Swaggo and served with Gin.

Requires Go 1.21 or later.

## Usage

Generate and import the Swaggo document package:

```bash
swag init
```

```go
import (
	"github.com/gin-gonic/gin"
	knife4go "github.com/jasonlabz/knife4go"
	_ "your-module/docs"
)

func InitRouters() *gin.Engine {
	router := gin.Default()
	if err := knife4go.InitSwaggerKnife(router); err != nil {
		panic(err)
	}
	return router
}
```

Open the UI at `/doc.html`. The Swagger JSON remains available at `/v3/api-docs` for compatibility.
